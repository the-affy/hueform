## Design Principles

### Independent Light & Dark Crafting
Light variants in SONDER are **not simple color inversions** of their dark counterparts. Each light variant is designed independently from paper and canvas fundamentals:
- **Clean, non-glaring backgrounds:** Soft warm whites, parchment tones, and cool mist rather than eye-straining `#FFFFFF`.
- **Deep contrasting typography:** Charcoal, deep navy, and forest pigments targeting **WCAG AA (≥ 4.5:1)** text contrast ratios.
- **Harmonious syntax hierarchy:** Balanced chromatic weight that separates keywords, functions, types, and strings naturally without cognitive fatigue.

### Complete Workbench Styling
Every theme styles the full VS Code surface:
- Editor tabs, tab borders, and active indicators
- Activity bar and sidebar explorer
- Terminal ANSI color palettes
- Integrated panels, problems view, and debug toolbar
- Command palette and quick pick menus
- Git decorations, diff editors, and status bar

## Installation

### From VSIX

```bash
code --install-extension sonder-2.0.0.vsix
```

### From Marketplace

Search for **SONDER** in the VS Code Extensions panel, or:

```bash
code --install-extension sonder-theme.sonder
```

## Accessibility

- WCAG AA contrast targets (≥ 4.5:1) met for all primary syntax tokens across all 22 themes.
- High readability in direct sunlight with the calibrated Light themes.
- Pure theme implementation — zero overhead, no background daemon, zero battery drain.
